# 场景布局和光源系统修改说明

## 修改概述
本次修改主要包括：
1. **模型位置调整**：将gltfClones模型移动到更远的位置，避免遮挡previewModel
2. **多彩光源系统**：添加4个彩色光源（红、绿、蓝、黄）
3. **光源标识模型**：在每个光源位置放置标识模型（rock01）

## 详细修改

### 1. 模型位置调整

**原始位置**（距离中心较近，容易遮挡previewModel）：
```
(-8.0f, 0.0f, 0.0f)    // 左
(8.0f, 0.0f, 0.0f)     // 右
(0.0f, 0.0f, -8.0f)    // 前
(0.0f, 0.0f, 8.0f)     // 后
```

**新位置**（距离更远，高度更高）：
```
(-20.0f, 5.0f, -15.0f)  // 左前方，抬高
(20.0f, 5.0f, -15.0f)   // 右前方，抬高
(-20.0f, 5.0f, 15.0f)   // 左后方，抬高
(20.0f, 5.0f, 15.0f)    // 右后方，抬高
```

**优势**：
- 模型距离previewModel更远，不会遮挡
- 抬高高度（y=5.0f）使场景更立体
- 形成更大的包围圈，增强场景深度感

### 2. 多彩光源系统

**光源配置**（4个彩色光源）：

| 光源 | 位置 | 颜色 | 强度 |
|------|------|------|------|
| 红色 | (-15.0f, 8.0f, -12.0f) | (1.0, 0.2, 0.2) | 1.0 |
| 绿色 | (15.0f, 8.0f, -12.0f) | (0.2, 1.0, 0.2) | 1.0 |
| 蓝色 | (-15.0f, 8.0f, 12.0f) | (0.2, 0.2, 1.0) | 1.0 |
| 黄色 | (15.0f, 8.0f, 12.0f) | (1.0, 1.0, 0.2) | 1.0 |

**光源位置特点**：
- 高度为8.0f，高于模型（y=5.0f）
- 形成对称的四角形布局
- 距离previewModel适中，提供良好的照明

### 3. 光源标识模型

**实现方式**：
- 在每个光源位置放置一个缩小的rock01模型（缩放因子0.15f）
- 标识模型使用与光源相同的位置
- 在mainPass和capturePass中都进行渲染

**渲染位置**：
- `drawFrame()`：在主渲染中绘制光源标识
- `drawSplitView()`：在三个视口中都绘制光源标识

### 4. 代码修改位置

**文件**：`examples/lightprobesh2/main.cpp`

**关键修改**：

1. **类成员变量**（第279-289行）：
   - 添加`LightSource`结构体
   - 添加`lightSources`向量
   - 添加`lightMarkers`向量

2. **函数声明**（第130-131行）：
   - 添加`InitializeLightSources()`函数声明

3. **PrepareScene()**（第375-376行）：
   - 调用`InitializeLightSources()`初始化光源

4. **InitializeLightSources()**（新增函数）：
   - 定义4个彩色光源
   - 为每个光源创建标识模型

5. **prepareData()**（第652-655行）：
   - 更新光源位置到mainPassData

6. **drawFrame()**（第679-681行）：
   - 绘制光源标识模型

7. **drawSplitView()**（三处修改）：
   - 在每个视口中绘制光源标识模型

## 着色器考虑

**MainPass着色器**需要支持：
- 多个光源（最多4个）
- 光源颜色信息
- 光源强度

**CapturePass着色器**需要支持：
- 相同的多光源照明
- 确保捕获的立方体贴图包含光源影响

## 使用效果

1. **视觉效果**：
   - previewModel清晰可见，不被其他模型遮挡
   - 4个彩色光源提供丰富的照明效果
   - 光源标识模型清楚地显示光源位置

2. **调试便利**：
   - 可以直观看到光源位置
   - 便于调整光源参数
   - 便于验证光照效果

3. **场景深度**：
   - 更大的场景布局
   - 更好的空间感
   - 更复杂的光照交互
